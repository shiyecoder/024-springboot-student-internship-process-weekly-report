# 大学生实习过程与周报管理系统 — 设计系统

视觉方向：**森林绿专业业务系统**。强调数据可读性、操作效率与状态辨识，不使用巨幅英文字母、装饰光效、悬浮球和大面积插画。

## 1. 色彩

| 令牌 | 色值 | 用途 |
|---|---|---|
| `--primary` | `#234E3B` | 顶栏、主按钮、当前菜单、关键数字 |
| `--secondary` | `#3A7D5A` | 次级按钮、筛选选中态、普通图表系列 |
| `--accent` | `#315F4C` | 链接、信息提示、图表对比系列 |
| `--bg` | `#F4F8F5` | 主内容区背景 |
| `--surface` | `#FFFFFF` | 卡片、表格、表单容器 |
| `--success` | `#2F7D55` | 已完成 / 已通过 / 正常 |
| `--warning` | `#B7791F` | 待处理 / 即将超时 |
| `--danger` | `#A93226` | 驳回、超时、异常、删除确认（仅小面积） |
| `--text` | `#1F2A24` | 正文 |
| `--text-sub` | `#63736B` | 辅助说明 |
| `--line` | `#DCE7E0` | 分隔线、表格边框 |

图表颜色由 `#234E3B / #3A7D5A / #315F4C / #6B8F7C / #9DB8A8 / #C9DBD0` 派生，同一含义跨页保持一致。
**状态不得只靠颜色表达**，必须同时有中文标签。

## 2. 字体与字号阶梯

系统中文无衬线：`-apple-system, "PingFang SC", "Microsoft YaHei", sans-serif`；数字列使用 `font-variant-numeric: tabular-nums`。

| 层级 | 字号 / 行高 | 字重 | 用途 |
|---|---|---|---|
| Display | 28 / 36 | 600 | 看板核心指标 |
| H1 | 20 / 28 | 600 | 页面标题 |
| H2 | 16 / 24 | 600 | 卡片标题、分组标题 |
| Body | 14 / 22 | 400 | 正文、表格 |
| Caption | 12 / 18 | 400 | 辅助说明、时间戳 |

## 3. 间距与圆角

- 基础单位 4px；间距序列 4 / 8 / 12 / 16 / 24 / 32。
- 卡片圆角 **6–8px**，按钮 6px，输入框 6px，标签 4px。
- 阴影只用于抽屉与弹窗：`0 8px 24px rgba(31,42,36,.12)`；卡片不投影，用 1px 边框。
- 内容区外边距 24px。

## 4. 框架尺寸

- 桌面端：左侧菜单 **220px**（折叠 64px）、顶部栏 **56px**、内容区自适应。
- 表单标签宽 **100–120px**，单列输入宽 **360–520px**；搜索下拉框 **180–240px**。
- 表格行高 44px，表头 40px，表头不写死宽度，按内容自适应并允许横向滚动。
- 首页按 1440×900 设计为一屏，不出现纵向滚动条。

## 5. 组件规范（详见 components.md）

按钮 / 输入 / 下拉 / 日期 / 表格 / 卡片 / 标签 / 抽屉 / 弹窗 / 分页 / 时间轴 / 图表容器 / 上传。

## 6. 角色视觉区分

| 角色 | 落地形态 | 主色用法 | 首页 |
|---|---|---|---|
| 实习管理员 admin | 后台管理（侧边栏 + 顶栏） | 深绿顶栏 + 全量菜单 | 实习质量看板 |
| 校内指导教师 teacher | 后台管理 | 深绿顶栏 + 精简菜单 | 待批阅工作台 |
| 企业导师 mentor | 后台管理（窄菜单） | 辅助绿顶栏标识 | 到岗与考勤录入 |
| 学生 student | 门户 / 前台风格 | 浅绿导航 + 内容流 | 我的实习 |

同一系统内四类角色从「导航形态 + 首页布局 + 强调色深浅」三处区分，不靠换字体。
